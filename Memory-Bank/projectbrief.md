# Blockchain Wallet Analysis Project Brief

## Core Objectives
- Track whale and market maker wallet activities on Ethereum and Arbitrum
- Analyze transaction flows, volumes, and fund directions
- Generate real-time trading signals based on whale movements
- Deliver alerts via Telegram bot

## Target Blockchains
- Primary: Ethereum and Arbitrum
- Future expansion: Other EVM-compatible chains

## Key Deliverables
- Telegram bot for delivering trading signals
- Wallet monitoring system with configurable alerts
- Transaction flow analysis engine
- API integrations with blockchain explorers

## Success Metrics
- Accurate identification of significant fund movements
- Timely notification delivery (near real-time)
- Actionable trading signals with clear context
- Reliable system with minimal downtime

## Project Scope
- IN scope: Monitoring public transactions, pattern recognition, alert generation
- OUT of scope: Trading execution, portfolio management, price prediction
